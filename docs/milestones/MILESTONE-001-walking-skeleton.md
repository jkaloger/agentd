One eligible iteration flows through the whole stack — polled, claimed, run by a real agent in its worktree, advanced on outcome — proving the end-to-end path before any layer is hardened. Everything not on the critical path is stubbed or minimal.

Releasable outcome: `agentd start` picks up one iteration and drives it to a terminal lazyspec state, observable in status/log.
